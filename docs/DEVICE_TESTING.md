# ATLAS CLIENT 1.5.0 — دليل الاختبار الفعلي

**الملف النهائي:** `ATLAS.mcaddon`
**الإصدار:** 1.5.0
**الهدف:** Minecraft Bedrock **26.60 (1.26.60)** أو أحدث
**الحزم:** Behavior Pack + Resource Pack داخل ملف واحد
**التجارب:** لا يحتاج أي Experiments

> **حالة الاختبار:** النسخة 1.2.0 سبق أن شُغّلت على Bedrock Dedicated Server 1.26.60.6 وظهر تحميل السكربتات والأحداث والأمر و`worldLoad` في السجل بدون أخطاء. **النسخة 1.5.0 لم تُعد اختبارها على الخادم في هذه البيئة.**
> لم تُختبر 1.5.0 على iPhone أو PS5 أو بواجهة لاعب حقيقي أو على Mega10.
> هذا الملف عبارة عن **قوائم اختبار وخطوات تحقق**، وليس تقرير نجاح. لا تعتبر أي بند ناجحاً حتى تنفذه فعلياً على الجهاز.
> النتائج الآلية موجودة في [`TEST_REPORT.md`](TEST_REPORT.md).

## 0. قبل البدء

1. خذ نسخة احتياطية من العالم الذي ستستخدمه.
2. استخدم **عالماً تجريبياً** أولاً، وليس عالمك الأساسي أو سيرفراً عاماً.
3. تأكد أن Minecraft نسخة **26.60 أو أحدث**.
4. فعّل **Settings → Creator → Content Log GUI** لرؤية أخطاء التحميل.
5. لا تفعّل أي Experiments.
6. إذا كانت لديك حزمة ATLAS قديمة بنفس UUID، احذفها من العالم/الحزم أولاً ثم استورد الملف الجديد.
7. لا تفك ضغط `ATLAS.mcaddon` ولا تعيد تجميعه يدوياً. الملف يجب أن يبقى بصيغة `.mcaddon`.

### التحقق من الملف قبل النقل

من مجلد المشروع:

```bash
npm ci
npm run check
sha256sum ATLAS.mcaddon
```

`npm run check` يشغّل typecheck والاختبارات والبناء والتحقق من الأرشيف. سجّل ناتج `sha256sum` إن أردت التأكد من أن الملف الذي وصل إلى الجهاز هو نفسه.

### 1.4 حفظ الإعدادات بعد إغلاق العالم

نفّذ هذا الاختبار بعد تغيير إعدادات مختلفة، وليس بعد إعداد واحد فقط:

1. غيّر الثيم إلى **Violet**.
2. غيّر اللغة إلى **العربية**.
3. أطفئ **Coordinates** من HUD.
4. أطفئ قطعة درع واحدة من **HUD editor**.
5. غيّر حد المتانة إلى قيمة مختلفة، مثل `35%`.
6. غيّر معدل تحديث HUD إلى قيمة مختلفة.
7. اخرج من العالم باستخدام **Save & Quit** (وليس إنهاء التطبيق قسرياً).
8. أعد فتح العالم نفسه وانتظر بضع ثوانٍ.

| ✔ | النتيجة المتوقعة |
|---|---|
| [ ] | الثيم واللغة ما زالا محفوظين |
| [ ] | Coordinates ما زالت مغلقة |
| [ ] | قطعة الدرع ما زالت مخفية |
| [ ] | حد المتانة ومعدل التحديث محفوظان |
| [ ] | سطر HUD يظهر بالعربية وبالإعدادات المحفوظة |
| [ ] | المواقع وإحصائيات القتال ما زالت موجودة |

> الإعدادات تُحفظ فور كل تغيير في **Dynamic Properties الخاصة باللاعب**. الاختبار الآلي يحاكي خروج اللاعب وعودته ويقرأ الإعدادات من التخزين من جديد. إغلاق العالم فعلياً على iPhone يبقى بنداً يدوياً حتى تُنفذه.
> إذا أغلق تطبيق Minecraft قسرياً قبل أن يحفظ العالم بيانات اللاعب، فقد لا تُحفظ آخر التغييرات. استخدم **Save & Quit** عند اختبار الحفظ.

### 1.5 استيراد إعدادات ATLAS1 القديمة

الرموز القديمة تبدأ بـ `ATLAS1-` وتحتوي على 20 تبديلاً فقط من الإصدار السابق.

1. افتح **Settings → Import settings code**.
2. الصق رمز ATLAS1 القديم الخاص بك، أو استخدم رمز الاختبار التالي:

   ```
   ATLAS1-2106lv1ugh
   ```

   هذا الرمز للاختبار فقط: الثيم Violet، اللغة العربية، Coordinates مغلقة، Compact مغلق، حد الصحة 8.
3. اضغط **Apply**.
4. راقب الرسالة، ثم افتح HUD وSettings للتأكد من القيم.
5. افتح **Export settings code** وتحقق أن الرمز الجديد يبدأ بـ `ATLAS2-`.

|---|---|
| [ ] | رسالة نجاح الاستيراد |
| [ ] | الثيم واللغة والتبديلات القديمة (20) تُطبّق وتُحفظ |
| [ ] | لوحات 1.1.0/1.2.0 (WASD، CPS، الدروع، الجرعات، التوتيم، تنبيه المتانة) تعمل بالقيم الافتراضية |

### 1.6 SERVER MANAGER (iPhone)

> هذا القسم **دفتر عناوين مع خطوات اتصال يدوية**، وليس متصلاً. لا يوجد زر CONNECT، والحالة تبقى `Unknown`، ولا تُعرض ONLINE/OFFLINE أو Ping أو عدد لاعبين. اختبر الواجهة والحفظ هنا، ثم اتصل يدوياً من شاشة Play إن كانت المنصة تسمح.

| ✔ | الاختبار | النتيجة المتوقعة |
|---|---|---|
| [ ] | فتح **SERVER MANAGER** | يظهر العدد والحالة الحالية وملاحظة أن الإضافة لا تستطيع الاتصال |
| [ ] | إضافة سيرفر IPv4 مثل `203.0.113.10` بمنفذ `19133` | يُحفظ الاسم والعنوان والمنفذ والتصنيف والمنطقة |
| [ ] | إضافة نطاق مثل `play.example.com` بمنفذ `19132` | يُقبل ويظهر بالحروف الصغيرة |
| [ ] | إدخال `host:19132` داخل حقل العنوان | رسالة تطالب بوضع المنفذ في حقل المنفذ، ثم يعاد فتح النموذج دون حفظ |
| [ ] | إدخال `http://example.com` أو مسافة أو نطاق غير صالح | يُرفض برسالة واضحة ولا يُحفظ |
| [ ] | إدخال منفذ `0` ثم `70000` | يُرفض في الحالتين |
| [ ] | تكرار العنوان والمنفذ نفسه | رسالة «محفوظ بالفعل» ولا تُضاف نسخة ثانية |
| [ ] | تعديل الاسم والوصف | تظهر القيم الجديدة بعد الحفظ |
| [ ] | إضافة إلى المفضلة | تظهر النجمة وتبقى بعد إعادة الفتح |
| [ ] | **تحديد كسيرفر حالي (يدوياً)** | تظهر «محدد منك» ووقت آخر تحديد، ولا يظهر ادعاء اتصال |
| [ ] | تحريك السيرفر لأعلى/أسفل | يتغير الترتيب ويُحفظ |
| [ ] | **Direct Join** بعنوان خاطئ ثم آخر صحيح | الأول يُرفض، والثاني يفتح دليل الاتصال ويعرض العنوان والمنفذ الصحيحين |
| [ ] | **Send address to chat** | يظهر العنوان في الدردشة؛ لا يوجد زر نسخ لأن الحافظة غير متاحة |
| [ ] | **Connection guide** | يذكر `Play → Servers → Add Server` والمنفذ، ولا يوجد زر CONNECT |
| [ ] | حذف سيرفر مع التأكيد | يُحذف السجل فقط، ولا يتأثر العالم |
| [ ] | الخروج بـ **Save & Quit** ثم إعادة فتح العالم | تبقى السيرفرات والمفضلة والترتيب وآخر عنوان Direct Join |
| [ ] | فحص الحالة بعد كل ما سبق | تبقى `Unknown`؛ لا أرقام ONLINE أو Ping أو لاعبين وهمية |

> **iPhone:** ماينكرافت على iOS يوفّر **Servers → Add Server**، لذلك أدخل العنوان والمنفذ هناك بعد حفظهما في ATLAS. الإضافة نفسها لا تستطيع فتح تلك الشاشة أو الضغط على أزرارها.

### 1.7 ملاحظات خاصة بلمس iPhone

- استخدام الأداة قد يحتاج ضغطاً/تحديداً حسب إعدادات التحكم. إذا لم تفتح القائمة، استخدم `/atlas:menu`.
- لا توجد طريقة رسمية لقراءة ضغطات لوحة المفاتيح أو أزرار اليد. WASD هي **متجه حركة**، وليست ضغطات مفاتيح.
- لا تستطيع الإضافة إنشاء أيقونة قابلة للنقر أعلى يمين الشاشة أو التقاط ESC.
- HUD يظهر في شريط الإجراءات فوق شريط الأدوات، وليس لوحة مخصصة في أعلى اليمين.

### 2.3 SERVER MANAGER على PS5

| ✔ | الاختبار | النتيجة المتوقعة |
|---|---|---|
| [ ] | فتح **SERVER MANAGER** من `/atlas:menu` | يفتح ويعمل كدفتر عناوين |
| [ ] | إضافة عنوان ومنفذ وتعديله ثم حذفه | تُحفظ العمليات وتُستعاد بعد إعادة الدخول |
| [ ] | البحث عن زر **Add Server** أو **CONNECT** داخل ATLAS | لا يوجد؛ الإضافة لا تدّعي اتصالاً |
| [ ] | محاولة استخدام العنوان للاتصال من واجهة PS5 | **لا يوجد Add Server على PS5**؛ لا يمكن للإضافة إضافته أو تجاوزه. سجّل النتيجة كقيد منصة |

> **PS5:** لا تعتبر وجود SERVER MANAGER دليلاً على إمكانية الاتصال بسيرفر مخصص من PS5. لا تدّعِ نجاح الاتصال حتى تجرب مساراً رسمياً تدعمه المنصة.

### 2.4 ما لا يمكن اختباره على PS5

- ضغطات أزرار يد PS5 الفيزيائية: غير متاحة للإضافة.
- Mouse LMB/RMB الفيزيائي: غير متاح؛ المؤشرات تعكس أحداث اللعب.
- موضع HUD أو حجم الخط أو الشفافية: غير متاحة في Script API.
- استيراد الملف من ذاكرة PS5: يعتمد على المنصة، ولم يُختبر.
- إدخال سيرفر مخصص من واجهة PS5: **لا يوجد زر Add Server**، والإضافة لا تستطيع إضافته.

## 3. السيرفرات العامة: ما يعمل وما لا يعمل

القاعدة الأساسية: **الإضافات في Bedrock مرتبطة بالعالم، وليست تعديلاً على جهاز اللاعب.** لا تستطيع إضافة مفعّلة على iPhone أن تحقن HUD أو أوامر في عالم سيرفر عام لا يملك الحزمة.

| البيئة | HUD والقوائم | المواقع والإعدادات | `/atlas:menu` | شريط التحديد | الحالة |
|---|---|---|---|---|---|
| عالم محلي تملكه وفيه الحزمتان | متوقع أن يعمل | تُحفظ في العالم/اللاعب | يعمل بدون غش | إن كانت الواجهة مدعومة | يحتاج اختبار جهاز فعلي |
| Realm تملكه وفيه الحزمتان | يعتمد على دعم Realms للحزم | يعتمد على العالم | قد يعمل | يعتمد على العالم | **غير مُختبر** |
| سيرفر عام لا يملك ATLAS | لا يعمل | لا يعمل | لا يعمل | لا يعمل | ليس عطلاً؛ الحزمة غير موجودة في العالم |
| سيرفر عام يسمح/يثبّت ATLAS | قد يعمل حسب إعدادات السيرفر | قد تُحفظ أو تُمنع حسب السيرفر | قد يمنعه السيرفر | قد يكون معطلاً | **غير مُختبر** |

| Mega10 | لم يُختبر | لم يُختبر | لم يُختبر | لم يُختبر | **لا تدّعِ التوافق** |

### ما قد يعمل إذا كانت الحزمة مفعّلة في العالم

- سطر HUD في شريط الإجراءات.
- قوائم Bedrock الأصلية.
- المواقع وحفظ الإعدادات داخل بيانات العالم/اللاعب، إن سمح السيرفر بذلك.
- تنبيهات الصحة والمتانة المحلية.
- علامات Locator إن كانت الميزة مدعومة وغير معطلة.

### ما لا يعمل عادةً في سيرفر عام

- تفعيل الحزمة من جهة اللاعب فقط.
- حقن HUD أو أوامر في عالم لا يملك الحزمة.
- تجاوز منع الأوامر المخصصة أو حماية السيرفر.
- قراءة أزرار يد PS5 أو نقرات الفأرة الفيزيائية.
- ضمان حفظ المواقع أو السيرفرات إذا كان السيرفر يمنع Dynamic Properties أو يعيد ضبط العالم.
- الاتصال بسيرفر خارجي من داخل الإضافة: غير متاح في Script API مهما كانت حالة السيرفر.

### قواعد الاستخدام

- لا تستخدم ATLAS لتجاوز قواعد سيرفر أو anti-cheat.
- لا يوجد في ATLAS Auto Clicker أو Aimbot أو أتمتة قتال.
- إذا منع السيرفر الحزمة أو الأمر، فهذا قرار السيرفر وليس عطلاً يمكن للإضافة تجاوزه.
